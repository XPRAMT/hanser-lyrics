# hanser-lyrics

Proofread timed lyrics (LRC) for hanser songs, maintained by XPRAMT.

[繁體中文](README_TW.md)

## Files

| File | Song |
| --- | --- |
| `lyrics/2233 - 元素協奏.lrc` | 2233 - 元素協奏 |
| `lyrics/hanser - 水星.lrc` | hanser - 水星 (Japanese + Chinese translation) |

## Format

- UTF-8 (with BOM) LRC.
- Each line: `[line start]<line start>lyric<line end>`.
